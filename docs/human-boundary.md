# Decide by the required evidence

| Request | Decision and reason |
| --- | --- |
| Photograph an authorized store display today | Human required for the requested current first-hand evidence. |
| Find an existing public photo | Digital search is sufficient; no new observation requested. |
| Ask someone who has never seen this product what it does | Human required; do not prime or simulate the first-time participant. |
| Explain what this landing page communicates | Agent analysis is sufficient unless real reader evidence is requested. |
| Observe a real user attempting signup | Human required; automated functional checks cannot measure that person's experience. |
| Verify a signup button submits correctly | Automation is sufficient when functional behavior is the acceptance criterion. |
| Which output do real readers prefer? | Human preference required; permit ties and report sample limitations. |
| Compare two outputs against a rubric | Agent evaluation is sufficient unless the rubric requires actual participants. |
| Do actual readers find this credible? | Human judgment required, but perceived credibility is not factual truth. |
| Improve the credibility of this wording | Agent editing may suffice; optional reader validation is a separate step. |
| Have a person conduct the authorized offline call | Human required when actual human conversation is material. |
| Find published opening hours | Research first; no intermediary needed if authoritative data satisfies the request. |
| Obtain the designated approver's signature | Route to that person, not an arbitrary marketplace participant. |
| Perform an act requiring a verified qualification | Human boundary recognized, but submission remains blocked until qualification and scope are established. |
| Prepare a summary for a consequential review | Agent can prepare; required final authorization stays with the accountable person. |

## Required, optional, or unclear

Name the completion criterion before choosing a route. “Give me feedback” commonly permits agent feedback. “Get actual human feedback” requires a real participant. “Will customers like this?” may mean a reasoned prediction or new preference evidence; distinguish those before claiming to know actual preferences.

Where agent analysis is sufficient, do it and identify it as analysis. If representative human evidence is required, define population, sampling, consent, and scope; one available participant is not a representative study. Prepare materials and checks without replacing the human evidence.

Physical subject matter does not always demand a visit. Current, trustworthy digital evidence can satisfy some verification requests. Conversely, a fully digital task can still require an actual person's perception. Decide by the evidence contract, not the medium.

Recognizing a human boundary and authorizing Taskin submission are separate decisions. No suitable person, refusal, missing access, uncertain credentials, or required principal approval are valid reasons to stop before submission and explain the unresolved requirement.
